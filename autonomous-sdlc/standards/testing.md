# Testing Standards

- Validate both HTML prototypes in a browser after any visual or interaction change.
- Check desktop and mobile-sized layouts, especially the phone-frame presentations already used in the prototypes.
- Test navigation states, toggles, click handlers, and any scripted transitions.
- Record manual evidence in `qa-report.md` using exact pages and behaviors tested.
- If a change is risky enough to deserve automation, add a follow-up task to introduce the smallest useful automated check.
