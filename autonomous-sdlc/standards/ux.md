# UX Standards

- Preserve the repo's current premium, editorial, mobile-first prototype style.
- Design for a phone-first canvas, then verify the surrounding presentation still works on larger screens.
- Use typography intentionally. Existing prototypes already use a serif plus sans pairing; new work should feel consistent unless the spec says otherwise.
- Motion should support understanding, not decoration. Prefer clear state changes and restrained transitions.
- Maintain strong readability and visible interaction states. Subtle styling is fine, ambiguous behavior is not.
