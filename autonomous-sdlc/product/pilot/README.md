# Pilot Readiness

Use these documents when preparing a real pilot release from the current repo state.

## Included Artifacts
- `launch-checklist.md`: release readiness and evidence gates
- `support-runbook.md`: what to check first when pilot users report issues
- `rollback-notes.md`: what to revert and how to prove the rollback worked
- `pilot-metrics-review.md`: the metrics to review during the pilot window

## Rule
Do not treat a green CI run as pilot approval on its own. The checklist, support path, and rollback notes must be current before any real release decision.
