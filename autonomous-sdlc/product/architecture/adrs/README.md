# ADRs

Use this folder for architecture decision records that survive beyond one feature.

## When To Add An ADR
- choosing the production frontend stack
- choosing the host mobile stack
- choosing database, auth, or realtime approach
- choosing hosting, deployment, or observability platforms
- reversing a previous architecture choice

## Suggested ADR Shape
- Title
- Status
- Context
- Decision
- Consequences
- Alternatives considered

## Rule
If a decision would materially change implementation, infrastructure, security, or delivery, record it here instead of burying it in a feature plan.
