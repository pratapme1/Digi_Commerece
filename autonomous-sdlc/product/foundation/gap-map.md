# Gap Map

## Attendee Surface
### Already Proven In `spaces_final.html`
- Premium card-rendering patterns for contact, menu, and visual content
- Minimal chrome and typography-led presentation
- Save-first interaction posture on rendered content

### Still Missing But Required
- Entry screen after QR scan
- Name entry for identified spaces
- Multi-format overview with grouped collections
- Active search state from local cache
- Host pin notification and live spotlight behavior
- Loading skeleton, empty-space state, expiry warning, and expired-session state
- Offline and reconnect messaging defined in the UX guide

## Host Surface
### Already Proven In `spaces_host.html`
- Dashboard direction with space cards and a dominant Go Live call to action
- Space editor with edit or preview behavior
- Live panel glance-first design with a limited control set

### Still Missing But Required
- Onboarding steps for phone, OTP, and account creation
- Brand setup flow
- QR code screen and download actions
- Go-live confirmation and scheduled session flow
- Bulk import flow and validation states
- Session summary, analytics, team management, and space settings
- Error states for OTP, verification, image upload, and import failures

## Cross-Surface Gaps
- No shared entity model for spaces, sessions, cards, attendees, or analytics
- No logical route map tying host and attendee flows together
- No session-state contract for draft, scheduled, live, ended, or restarted sessions
- No canonical event dictionary for presence, saves, views, and live actions
- No shared definition of identified versus anonymous data handling
