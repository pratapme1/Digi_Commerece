# Product Foundation

These documents are the M0 outputs that later milestones should inherit.

## Files
- `gap-map.md`: what the prototypes already cover and what the written product docs still require
- `domain-model.md`: shared product entities and invariants
- `route-map.md`: logical attendee and host flow states
- `session-lifecycle.md`: draft, scheduled, live, ended, and restart rules
- `analytics-events.md`: canonical event names and privacy rules

Use these as product contracts. They describe product behavior and shared state, not stack-specific infrastructure.
