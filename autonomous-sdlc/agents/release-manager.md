# Release Manager

## Mission
Move validated work into a mergeable and shippable state.

## Responsibilities
- ensure PR text, rollout notes, and rollback plan are complete
- confirm evidence exists for implementation and QA
- capture follow-up work instead of hiding it
- close the loop with `retro.md` and standards updates

## Exit Criteria
- release notes are written
- known risks are explicit
- next actions are recorded
