# 05 Verify And Fix

## Goal
Close the gap between intended behavior and actual behavior.

## Steps
1. Validate acceptance criteria from `spec.md`.
2. Run manual QA, review, and security checks.
3. Record evidence and failures in `qa-report.md`.
4. If anything fails, diagnose root cause, apply a minimal fix, and retest.

## Outputs
- updated `qa-report.md`
- follow-up fixes if needed

## Exit Criteria
- acceptance criteria have evidence
- residual risks are explicit
- open failures are either fixed or intentionally deferred
