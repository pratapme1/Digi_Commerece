# 02 Discover And Spec

## Goal
Ground the work in standards and produce a decision-ready specification.

## Steps
1. Load relevant files from `standards/index.yml`.
2. Inspect the current repo and existing user-facing behavior.
3. Write the problem, desired outcome, scope, non-goals, and acceptance criteria.
4. Clarify ambiguity before planning.

## Outputs
- updated `spec.md`

## Exit Criteria
- acceptance criteria are testable
- scope and non-goals are explicit
- unresolved ambiguity is minimal or called out
