# 04 Implement

## Goal
Ship the planned work through small, validated changes.

## Steps
1. Convert the plan into ordered tasks.
2. Implement one slice at a time.
3. Validate after each slice with the strongest local checks available.
4. Update task state as work completes or changes.

## Outputs
- updated repository files
- updated `tasks.md`

## Exit Criteria
- all planned tasks are either complete, deferred, or removed with explanation
- the code matches the approved plan or the plan is updated to reflect reality
