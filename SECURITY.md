# Security Policy

## Supported Scope
This repository currently hosts prototypes and workflow documentation rather than a production service. Security reports should still be filed for:
- embedded secrets or credentials
- unsafe third-party scripts
- privacy issues in prototype flows
- workflow automation that could take unsafe actions

## Reporting
Please report security concerns privately to the repository owner instead of opening a public issue for exploitable problems.

## Expectations
- Do not commit secrets.
- Treat future auth, payment, upload, and personal-data features as high-risk.
- Follow `autonomous-sdlc/process.md` for sensitive changes.
