Flow Principle
Attendees only see one space at a time. The QR resolves into a single live overview, then only that space's collections, search results, and save actions.
Overview
Slice 2 replaces the showcase handoff with a real space overview: featured item, live search, grouped collections, and an empty-space fallback.
Collections
Collection views still use the existing high-fidelity content screens, but attendees now reach them only through the overview or search flow.
Save Behavior
Saving stays device-first. The prototype now shows the native-share handoff as a session-scoped action instead of pretending Spaces stores the item itself.
Space Presets
Use the preset pills above the phone to switch the reviewed QR target between a meeting, restaurant, store, event, or live-but-empty space.
Live Signals
Slice 3 adds the room-state layer on top of the overview: host pin, five-minute warning, offline mode, and live end-of-session overlay.
Bootstrap States
Slice 1 remains intact underneath: live, inactive, ended, identified, and anonymous entry all still gate the attendee before the overview appears.
